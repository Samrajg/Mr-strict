# Mr.Strict

AI-assisted student answer-sheet evaluation, reference-answer similarity analysis, and automated grading platform.

## Architecture

This project is organized into two main components:

- **`frontend/`**: Web user interface (Deployable to Vercel).
- **`backend/`**: REST API, evaluation engine, text extraction, sentence embeddings, and scoring services (Deployable to Render).

## Getting Started

Refer to the respective README files in the `frontend/` and `backend/` directories for setup and development instructions.
